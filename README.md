# JS-Strong

A learning collection of JavaScript algorithm exercises, data structures and core language concepts, with some crash-course notes. Files are mostly standalone scripts that print results with `console.log`; they are not a library and have no automated tests.

## Run an example

```sh
node "Algo and challenges/palindrome.js"
```

Tested with Node 24. The TypeScript crash course is browser-based: open `TypeScript_crash_course/index.html` (compile `script.ts` with `tsc` after editing).
